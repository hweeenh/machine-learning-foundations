# machine-learning-foundations
A practical exploration of foundational machine learning concepts using Python and healthcare-oriented datasets.

## Topics
1. Linear Regression
2. Logistic Regression
3. Bias-Variance Tradeoff
4. Cross-Validation
5. Classification Metrics
6. PCA
7. Regularisation
8. Naive Bayes

## Approach

Each notebook focuses on understanding the underlying concept of each topics, exploring a real-world dataset, implementing the method in Python, and interpreting the results.
